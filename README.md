# Автоматизация теста к API Яндекс Самокат

Дипломный проект: автоматизация проверки статус-кода ответа при получении заказа по его трек-номеру.

## Описание сценария
1. Выполняется запрос на создание нового заказа (`POST /api/v1/orders`).
2. Из ответа сохраняется трек-номер заказа (`track`).
3. Выполняется запрос на получение заказа по трек-номеру (`GET /api/v1/orders/track`).
4. Проверяется, что код ответа (статус-код) равен `200`.

## Требования для запуска
- Установленный **Python 3**
- Установленные библиотеки **pytest** и **requests**

Установка зависимостей:
```bash
pip install pytest requests
```

## Запуск теста
Перед запуском убедитесь, что в файле `configuration.py` указан актуальный `URL_SERVICE` запущенного тестового стенда.

Запуск из терминала в корневой директории проекта:
```bash
pytest
```
